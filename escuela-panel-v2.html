Ayuda

Preguntas frecuentes

Información básica para resolver las dudas más habituales durante el recorrido.

¿Debo completar los encuentros en orden?

Sí. Se recomienda avanzar progresivamente desde el Encuentro 1 hasta el Encuentro 8 para aprovechar la continuidad de los contenidos.

¿Puedo volver a ver un encuentro?

Podrás volver a ingresar a los encuentros disponibles para revisar sus contenidos y materiales.

¿Cuánto tiempo necesito para cada encuentro?

La duración puede variar según el contenido y el tiempo dedicado a las actividades. El programa está diseñado para realizarse de manera flexible.

¿Cómo obtengo la certificación?

La certificación se habilitará cuando hayas completado los ocho encuentros y la encuesta final de satisfacción.

¿Este programa reemplaza una consulta psicológica?

No. Se trata de un programa formativo y psicoeducativo. No reemplaza procesos psicoterapéuticos ni atención psicológica individual.

Soporte y orientación

¿Necesitás realizar una consulta?

Para dudas relacionadas con un encuentro específico podrás utilizar el acceso de consulta disponible dentro de cada aula.

Para consultas generales sobre acceso, materiales o certificación, comunicate con la coordinación de la Escuela para Padres FALCO®.

Las consultas serán respondidas dentro de las 48 horas hábiles.
